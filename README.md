# کسی اینجاست؟ — راه‌اندازی رایگان

## روش ۱: Render (رایگان)
1. این پوشه را در یک مخزن GitHub بگذار (github.com → New repository → فایل‌ها را آپلود کن).
2. در render.com وارد شو → New → Web Service → مخزن را انتخاب کن.
3. تنظیمات خودکار از render.yaml خوانده می‌شود (Runtime: Node، Plan: Free). Create را بزن.
4. بعد از چند دقیقه یک آدرس مثل https://is-anyone-here.onrender.com می‌گیری؛ همان را به همه بده.

نکته: پلن رایگان Render بعد از ۱۵ دقیقه بی‌استفاده می‌خوابد و اولین ورود بعدی حدود ۳۰ تا ۶۰ ثانیه طول می‌کشد.

## اجرای محلی
    node server.js
و بعد http://localhost:3000 (Node نسخهٔ ۱۸ به بالا؛ هیچ پکیجی لازم نیست).

## توضیحات
- حضور و پیام‌ها فقط در حافظهٔ سرور هستند و ذخیره نمی‌شوند.
- لابی حداکثر ۱۵۰ نفر و گوشهٔ خصوصی ۸ نفر ظرفیت دارد (در server.js قابل تغییر).
- گفت‌وگو با شخصیت‌های هوش مصنوعی به قابلیت داخلی کلود وابسته بود و اینجا کار نمی‌کند.
